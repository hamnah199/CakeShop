CAKESHOP WEBSITE — QUICK START

1. Extract this ZIP file.
2. Open the extracted "cakeshop-website" folder in VS Code.
3. Open config.js.
4. Replace 923001234567 with your WhatsApp number (Pakistan example: 923001234567).
   Use digits only: no + sign, spaces or dashes.
5. Open index.html in your browser (or use the VS Code Live Server extension).

Files:
- index.html   Home page
- product.html Product detail page (opens when a product is clicked)
- style.css    All styling and responsive layout
- script.js    Product data and page interactions
- config.js    WhatsApp number and currency settings

Ordering:
There is no cart checkout, payment gateway, shipping or delivery booking.
Each product has a detail page with an ORDER / ASK ON WHATSAPP button.

Note: Product photos and Google Fonts load from the internet, so an internet connection is needed for those.
